# ProfeECEP

Plataforma web para preparar la Evaluación de Conocimientos Específicos y Pedagógicos (ECEP) en Chile.

## Estado

Versión base 0.2 en desarrollo.

- Temario ECEP 2026 de Educación Básica Matemática
- Progreso por indicador
- Banco inicial de preguntas
- Diseño mobile-first

## Arquitectura actual

Sitio web estático modular preparado para evolucionar a una aplicación con autenticación, base de datos y estudio adaptativo.

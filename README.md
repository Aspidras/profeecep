# ProfeECEP

Plataforma web para preparar la Evaluación de Conocimientos Específicos y Pedagógicos (ECEP) en Chile.

## Versión 0.2

Piloto actual: **Educación Básica Matemática 2026**.

### Funciones actuales
- Mapa del temario por dominio y subdominio.
- Progreso por indicador.
- Banco inicial de 15 preguntas propias.
- Práctica rápida mezclada.
- Práctica por dominio.
- Retroalimentación inmediata.
- Historial acumulado de aciertos y errores por dominio.
- Lista de preguntas para revisar.
- Diseño mobile-first.
- Persistencia local en el navegador.

## Fuente del temario

La estructura se basa en el temario oficial ECEP 2026 de Educación Básica Matemática. Las preguntas de práctica son contenido propio de ProfeECEP y no corresponden a preguntas oficiales de CPEIP.
